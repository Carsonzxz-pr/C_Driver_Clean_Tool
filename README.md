# C盘自动清理工具

## 项目简介

C盘自动清理工具是一款面向 Windows 的图形化实用程序，专门用于释放系统盘空间。程序会自动扫描常见的临时目录、缓存以及回收站，并在清理前准确预估可释放容量，帮助用户快速、安全地整理 C 盘。

## 核心功能

- 一键扫描：启动即自动检测可清理项目，同时显示体积和说明。
- 快速清理：优先使用 Windows 原生命令批量删除，失败时自动回退到逐个删除的安全模式。
- 系统融合：后台调用 `cleanmgr`，补充释放磁盘清理工具可处理的内容。
- 并行处理：多线程并发清理不同目录，缩短等待时间并实时刷新进度。
- 可视化反馈：tkinter GUI 提供进度条、日志面板和状态提示，支持自定义选择清理项目。

## 清理范围

| 清理项目         | 路径                                                         | 说明                       |
|------------------|--------------------------------------------------------------|----------------------------|
| 系统临时文件     | `C:\\Windows\\Temp`                                      | Windows 生成的临时文件     |
| 用户临时文件     | `%USERPROFILE%\AppData\Local\Temp`                        | 当前用户缓存和临时文件     |
| 回收站           | `C:\\$Recycle.Bin`                                         | 清空所有用户的回收站内容   |
| Windows 更新缓存 | `C:\\Windows\\SoftwareDistribution\\Download`          | Windows Update 下载缓存    |
| 预读取缓存       | `C:\\Windows\\Prefetch`                                  | 系统预读取产生的缓存文件   |
| IIS 日志         | `C:\\inetpub\\logs\\LogFiles`                          | IIS 服务器日志             |
| IE/Edge 缓存     | `%USERPROFILE%\AppData\Local\Microsoft\Windows\INetCache` | Internet Explorer 缓存目录 |

## 系统要求

- Windows 7/8/10/11（建议以管理员身份运行获得完整清理权限）。
- Python 3.8 及以上（仅在源码模式下需要，打包版包含运行时）。
- 约 50 MB 可用空间，用于临时文件和日志缓存。

## 使用方法

### 图形界面打包版（推荐）

1. 下载项目并解压。
2. 双击 `dist\C_Disk_Cleaner.exe`，如需管理员权限请右键选择“以管理员身份运行”。
3. 程序会自动扫描，确认后点击“开始清理”即可执行。

### 源码运行

1. 安装 Python（确保包含 tkinter 模块）。
2. 打开命令提示符或 PowerShell，并切换到项目目录：`cd /d C:\path\to\C_clean`。
3. 执行 `run.bat`（会优先尝试打包版，否则调用本地 Python）或直接运行 `python main.py`。

## 常见问题

- **为什么建议使用管理员权限？** 某些目录（如回收站、系统临时目录）只有管理员才能清空，否则会出现权限错误。
- **清理是否安全？** 程序仅针对临时文件和缓存，不会主动删除用户文档；操作日志会记录无法删除的项目便于排查。
- **清理速度慢怎么办？** 可先关闭正在运行的大型应用以减少文件占用，程序会在批量删除失败时自动切换为安全模式。
