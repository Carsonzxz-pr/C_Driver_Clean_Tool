# C盘自动清理工具

## 项目简介

这是一个Windows系统的C盘自动清理工具，能够自动执行类似于`cleanmgr`（磁盘清理工具）的功能，帮助用户快速清理系统临时文件、缓存文件等，释放C盘空间。

## 功能特点

### 🚀 自动化清理
- **一键启动**：打开软件即可自动开始清理流程
- **系统集成**：调用Windows内置的磁盘清理工具
- **快速策略**：自动在批量命令和安全删除之间切换，保证速度
- **并行处理**：多线程同时清理多个文件夹

### 🔍 智能扫描
- **深度扫描**：检测所有可清理的系统文件和临时文件
- **大小计算**：准确显示每个项目的占用空间
- **实时预览**：清理前显示可释放的空间大小

### 🛡️ 安全保护
- **权限检查**：自动检测并提示管理员权限
- **确认机制**：清理前需要用户确认操作
- **错误处理**：安全处理文件访问权限等问题

### 🎨 用户友好
- **图形界面**：直观的GUI操作界面
- **进度显示**：实时显示清理进度和日志
- **无需选择模式**：默认启用快速清理策略，避免选择困难

## 清理项目

本工具可以清理以下类型的文件：

| 清理项目 | 路径 | 描述 |
|---------|------|------|
| 临时文件夹 | `%TEMP%` | 系统和用户临时文件 |
| Windows临时文件 | `C:\Windows\Temp` | Windows系统临时文件 |
| 用户临时文件 | `%USERPROFILE%\AppData\Local\Temp` | 当前用户临时文件 |
| 回收站 | `C:\$Recycle.Bin` | 回收站文件（需要管理员权限） |
| Windows更新缓存 | `C:\Windows\SoftwareDistribution\Download` | Windows更新下载缓存 |
| 预读取文件 | `C:\Windows\Prefetch` | 系统预读取缓存文件 |
| IIS日志 | `C:\inetpub\logs\LogFiles` | IIS Web服务器日志文件 |
| 浏览器缓存 | `%USERPROFILE%\AppData\Local\Microsoft\Windows\INetCache` | Internet Explorer缓存文件 |

## 系统要求

- **操作系统**：Windows 7/8/10/11
- **Python版本**：Python 3.6 或更高版本
- **权限要求**：建议以管理员权限运行（获得最佳清理效果）
- **硬盘空间**：至少10MB可用空间

## 使用指南

### 1. 程序启动
- 双击 `dist\C_Disk_Cleaner.exe` 即可运行（推荐）

- 软件默认启用快速清理策略，无需手动选择模式
- 点击"开始清理"按钮，确认提示后即可执行

### 5. 查看结果
- 清理过程中会显示实时进度
- 操作日志显示详细的清理信息
- 清理完成后显示释放的空间大小

## 安全说明

### ⚠️ 重要提醒

1. **数据安全**
   - 清理操作是**不可逆**的
   - 建议在清理前备份重要数据
   - 程序只清理临时文件和缓存，不会删除用户文档

2. **权限要求**
   - 某些系统文件需要管理员权限才能清理
   - 建议以管理员身份运行程序
   - 没有管理员权限时，部分清理项目可能会失败

3. **文件占用**
   - 正在使用的文件无法被清理
   - 建议关闭不必要的程序后再进行清理
   - 错误信息会显示无法清理的文件

## 常见问题

### Q: 为什么需要管理员权限？
A: 某些系统目录（如回收站、Windows临时文件夹）需要管理员权限才能访问和清理。

### Q: 清理是否安全？
A: 是的，程序只清理临时文件和缓存，不会删除重要的系统文件或用户数据。

### Q: 清理后系统会变快吗？
A: 清理可以释放磁盘空间，但对系统运行速度的影响有限。主要作用是释放存储空间。

### Q: 为什么不再需要选择清理模式？
A: 新版本默认启用快速清理策略，程序会根据文件规模自动切换批量命令或安全删除，让用户不必纠结选项。

### Q: 必须安装 Python 才能运行吗？
A: 不需要。下载后的 dist\C_Disk_Cleaner.exe 已打包好运行时，可直接双击使用；仅在调试源码时才需要本地 Python 环境。

### Q: 程序如何兼顾速度与安全？
A: 大文件会使用Windows批处理命令批量删除，小文件则改用逐个删除的安全方式；若批量删除失败，还会自动回退到安全方式。

### Q: 可以定期自动运行吗？
A: 目前版本需要手动运行。您可以创建计划任务来定期自动执行清理。

### Q: 程序报错怎么办？
A: 查看操作日志中的错误信息，通常是权限问题或文件被占用。可以尝试：
- 以管理员权限运行
- 关闭其他程序后重试
- 检查磁盘是否有足够空间

## 技术说明

### 核心技术
- **语言**：Python 3.6+
- **GUI框架**：tkinter
- **系统调用**：subprocess, os
- **多线程**：threading（避免界面冻结）

### 清理原理
1. **系统清理**：调用Windows内置的`cleanmgr`工具
2. **批量快速清理**：对大体积目录使用`del /f /s /q`和`rmdir /s /q`
3. **安全清理**：对小体积目录逐个删除并清理空文件夹
4. **自动回退**：批量清理失败时自动切换到安全方式
5. **安全检查**：检查文件权限和占用状态
6. **错误处理**：记录无法清理的文件，不中断整个流程
